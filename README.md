# Раскладка плитки

Планировщик раскладки плитки в ванной: план пола и развёртка стен с подрезками, сантехника, двери и окна, розетки и выводы воды и канализации с проверкой попадания на швы, подсчёт плитки, затирки и клея с учётом слоя плитки и клея.

Открыть: https://bublzy.github.io/tile-planner/

Проекты хранятся в браузере. Перенос между устройствами — кнопки «Скопировать проект» и «Вставить проект».
